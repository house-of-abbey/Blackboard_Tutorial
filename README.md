# Blackboard System on Chip Development Board Tutorials

A collection of designs using both digital logic and software for the [Blackboard SoC development board](https://www.realdigital.org/hardware/blackboard) available from RealDigital Electrical & Computer Engineering Education. This provides a training ground for creating "Internet of Things" (IoT) applications and learning how to use the AMD (Xilinx) Zynq processes that integrate an ARM processor (PS) with adjacent digital logic (PL) using Vivado and Vitis design tools.
